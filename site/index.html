A hardened HTTP/1.1 parser for .NET

Zero-allocation request parsing with full RFC 9110/9112 validation, resource limits, and request-smuggling defenses — fused into a single zero-copy pass, in pure C#.

The hardened parser in pure C#. Dependency-free, runs on any .NET target. Full validation, returns a BinaryRequest.

Glyph11.Native and Glyph11.Pico are discontinued: their published versions stay on NuGet, but they get no further releases.

Install

dotnet add package Glyph11
